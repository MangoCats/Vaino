Flagged for review

Checked from Vaino's own play-history page — "flag this for review" — and only ever read here, never set or cleared: the checkbox is Vaino's, this is a worklist over what it wrote. Choosing one opens its profile, where the id review and boundary editor Vaino already offers are one click away.

Sync with a remote

Pull brings vainopi's own flags here, resolved by audio content rather than a local number — a flag on a recording or passage this library doesn't have yet is counted and reported, not silently dropped. It reads only the flags themselves over ssh, never a copy of the whole library, so it's quick even over vainopi's own slow WiFi. Push lands whatever identification/boundary/artist edits have accumulated here since the last push, and clears the flags they answer — batched, on request only: it briefly stops and restarts vainopi's own player, so it never runs on its own, and it still fetches a full comparison copy first.

e.g. pi@vainopi:/srv/library/vaino.db — an input's own placeholder text can't be selected or copied; this can.
